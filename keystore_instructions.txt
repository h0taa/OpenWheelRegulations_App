Open Wheel Regulations — Release Signing Instructions
=====================================================

The app builds an Android App Bundle (.aab) for Google Play. Play App Signing
manages the final signing key, but you still need an *upload* key to sign the
bundle you submit. Never commit keystores or passwords to version control.

1. Generate an upload keystore (run once)
-----------------------------------------
From a terminal (the JDK that ships with Android Studio includes keytool):

    keytool -genkeypair -v \
      -keystore owr-upload-keystore.jks \
      -keyalg RSA -keysize 2048 -validity 10000 \
      -alias owr-upload

You will be prompted for a keystore password, a key password, and your
distinguished-name details. Store the passwords in a password manager.

2. Tell Gradle where the keystore is (do NOT hardcode secrets)
--------------------------------------------------------------
Create a file named `keystore.properties` in the project root (this file should
be git-ignored):

    storeFile=/absolute/path/to/owr-upload-keystore.jks
    storePassword=********
    keyAlias=owr-upload
    keyPassword=********

Then add a signingConfig to app/build.gradle.kts that reads it, for example:

    import java.util.Properties
    val keystoreProps = Properties().apply {
        val f = rootProject.file("keystore.properties")
        if (f.exists()) f.inputStream().use { load(it) }
    }
    android {
        signingConfigs {
            create("release") {
                if (keystoreProps.isNotEmpty()) {
                    storeFile = file(keystoreProps.getProperty("storeFile"))
                    storePassword = keystoreProps.getProperty("storePassword")
                    keyAlias = keystoreProps.getProperty("keyAlias")
                    keyPassword = keystoreProps.getProperty("keyPassword")
                }
            }
        }
        buildTypes {
            getByName("release") {
                signingConfig = signingConfigs.getByName("release")
            }
        }
    }

3. Build the release bundle
---------------------------
    ./gradlew bundleRelease

The signed bundle is written to:
    app/build/outputs/bundle/release/app-release.aab

4. First upload
---------------
Upload the .aab in the Google Play Console. On first upload, opt in to Play App
Signing; Google will manage the app signing key and you keep the upload key.

Reminder: keep `owr-upload-keystore.jks` and `keystore.properties` backed up and
OUT of source control. Losing the upload key requires a key reset with Google.
